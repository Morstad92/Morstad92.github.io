Encrypted Google Drive Backup Utility

A privately operated backup workflow for storing client-side-encrypted recovery archives in Google Drive.

How it works

The utility uses rclone to transfer backup archives to Google Drive. Backup archives are encrypted locally with age before upload. Encryption keys are managed separately from Google Drive.

Google Drive access

Google OAuth authorizes the utility to use the Google Drive drive.file scope. This limited scope allows the utility to create and access files that it creates or that the user explicitly makes available to the app. The utility does not request blanket access to all files in Google Drive.

OAuth client credentials and rclone configuration are managed on the operator's local device, not through this website. Google may receive authentication and file-transfer information as part of providing its services.

About this website

This is a static, public information website. It has no login, file upload, Google sign-in, backup execution, or decryption capability. The website does not process backup files. Its hosting provider may process ordinary visitor request data to deliver the pages.

Use and availability

The utility is for personal backup and recovery operations, not a publicly offered file-storage service. Access is limited to the operator's authorized Google account.

For further information about Google data permissions, storage and retention, see the Privacy Policy.
