Privacy Policy

Last updated: November 1, 2026

Purpose

This policy describes a privately operated utility that backs up locally encrypted recovery archives to Google Drive using rclone and OAuth. This public website provides information only; it does not perform OAuth sign-in, collect Drive permissions, accept files, or run backups.

Google account data accessed

The utility requests only the Google Drive drive.file scope. With the operator's authorization, it can create, upload, locate, read, download and manage files within that limited app-accessible set. This can involve filenames, file IDs, sizes, timestamps and other file metadata, as well as the bytes transferred. It does not request general access to every Drive file or access to Gmail or Google Contacts.

Use and transfer of data

The utility uses authorized Drive access to upload encrypted backups, verify stored content, and retrieve those archives for recovery. Archives are encrypted on the operator's device with age before upload; decryption is performed locally. Google Drive holds encrypted archive bytes and may process file metadata and service information under Google's own policies.

The utility does not sell Google user data or use it for advertising. The website itself does not receive the files or OAuth tokens. Local credentials, tokens and encryption-key material are not intentionally published on the website.

Storage and retention

OAuth credentials and tokens are managed locally through the operator's rclone configuration. Encrypted archives are kept in the operator's authorized Google Drive account until removed under the operator's backup-retention procedures. The operator controls local copies and Google Drive files. Revoking access to the app prevents subsequent authorized Drive operations but does not itself erase files already stored.

Security limitations

Client-side age encryption protects archive contents before transfer, but cannot hide all associated file or account metadata from Google. Security also depends on the operator protecting local OAuth tokens, device access, encryption identities and recovery passphrases. No system can guarantee absolute security.

Website hosting

These static pages are hosted on GitHub Pages. There are no website forms, analytics scripts, advertising scripts or custom cookies in these pages. GitHub may collect technical request information, including IP addresses, according to its own policies when visitors access the website.

Control and questions

The utility is operated for personal use with an authorized Google account, and is not offered as a public service. The operator can review or revoke the app's Google account access through Google Account connections and manage uploaded archives directly in Google Drive. Questions about the utility can be directed to the application operator through their existing communication channel.

Policy updates

This page may be updated if the utility's behavior or data handling changes. The revision date above identifies the published version.
